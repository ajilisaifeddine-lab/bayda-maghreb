Write code in your own dialect. North African transpiler - Kabyle, Libya, Tunisia, Algeria, Mauritania.

### Supported Dialects

| Code | Name | File | Words | Type |
| :--- | :--- | :--- | :---: | :--- |
| kab | Kabyle | kabyle.json | 72 | Code |
| kab-lat | Kabyle Latin | kabyle-latin.json | 104 | Code |
| ly | Libya | libya.json | 337 | Code |
| tn-latn | Tounsi Franco | tunisia_franco.json | 205 | Code |
| dz | Dzair Arabic | algeria.json | 110 | Code |
| dz-latn | Dzair Franco | algeria_franco.json | 114 | Code |
| mauritania | Mauritania Gen Z | mauritania.json | 177 | Vocabulary |
